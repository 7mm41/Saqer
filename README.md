# 🦅 صقر ستور — Saqer Store

**متجر تطبيقات iPhone عربي بتوقيع فوري وتثبيت مباشر عبر الهواء (OTA)**

ثيم عصري فاخر بلمسة زجاجية (Liquid Glass) — حبر دافئ + برونزي ذهبي، بدون أي ألوان نيون.

## ما هذا المشروع؟

منظومة **صقر ستور** الكاملة، مبنية بـ HTML/CSS/JavaScript خالص بلا أي مكتبات أو خطوة بناء —
تعمل بفتح الملفات مباشرة أو عبر أي استضافة ثابتة. تتكوّن من ثلاث واجهات تتشارك نفس قاعدة البيانات
والهوية البصرية:

| الملف | الواجهة | الوصف |
|------|---------|-------|
| `index.html` | **الموقع** | صفحة المتجر: عرض التطبيقات، الشهادات، شرح آلية التوقيع، والتثبيت عبر الهواء. |
| `admin.html` | **لوحة التحكم** | إدارة كاملة: إضافة/تعديل/حذف التطبيقات والشهادات، وقائمة طلبات التوقيع مع إحصائيات. |
| `app.html` | **التطبيق (IPA)** | عميل المتجر على شكل تطبيق iPhone قابل للتثبيت (PWA): تصفّح، بحث، توقيع، تحميلات، حساب. |

### ملفات مشتركة

```
assets/theme.css   نظام التصميم (توكِنات الألوان، الوضع الداكن، RTL، المكوّنات، الحركة)
assets/store.js    طبقة البيانات المشتركة (تطبيقات + شهادات + طلبات توقيع) + الأيقونات + الأدوات
manifest.webmanifest   تعريف تطبيق الويب التقدّمي (PWA)
sw.js              Service Worker للعمل دون اتصال (يخزّن هيكل التطبيق)
icons/             أيقونة المتجر (SVG + PNG بأحجام 180/192/512)
```

> يبقى `store-popup.js` و`index`ه السابق كأداة نافذة تواصل مستقلة يمكن دمجها لاحقًا في الموقع.

## الهوية البصرية

مستوحاة من مصادر إلهام حديثة (21st.dev، Refero، Supahero، Motion، 60fps) وموصى بها عبر
سكِل **UI/UX Pro Max**:

- **النمط:** Liquid Glass — أسطح زجاجية شفّافة، ظلال ناعمة، حواف دائرية.
- **الألوان:** حبر دافئ `#1c1917` + برونزي ذهبي `#a16207` على خلفية حجرية `#faf9f7` — **لا ألوان نيون**.
- **الخطوط:** Noto Kufi Arabic للعناوين + Tajawal للنصوص.
- **الوصول:** تباين ≥ 4.5:1، حلقات تركيز واضحة، احترام `prefers-reduced-motion`، أهداف لمس ≥ 44px.
- **يدعم:** العربية (RTL) بالكامل، الوضع الفاتح والداكن، والجوّال أولًا.

## آلية التوقيع والتثبيت عبر الهواء (OTA)

يستخدم المشروع **آلية iOS الرسمية** للتثبيت المباشر:

```
itms-services://?action=download-manifest&url=https://<host>/manifest.plist
```

خطوات المستخدم داخل الموقع/التطبيق:

1. **تسجيل الجهاز** — إدخال معرّف `UDID` مرة واحدة.
2. **اختيار التطبيق والشهادة** — مؤسسية (Enterprise) / تطوير (Development) / Ad-Hoc.
3. **التثبيت** — يوقّع الخادم الحزمة ويولّد `manifest.plist`، فيظهر رابط تثبيت مباشر.

الواجهة الحالية تحاكي خط أنابيب التوقيع بالكامل (تحقّق الشهادة ← حقن ملف التعريف ← `codesign` ←
توليد `manifest.plist` ← رابط `itms-services`) وتولّد روابط بالصيغة الحقيقية.

## 🔌 التفعيل الحقيقي (خادم الإنتاج)

> ⚠️ **مهم وصريح:** التوقيع الفعلي لملفات IPA لا يمكن أن يتم في المتصفّح — يتطلّب خادمًا وشهادات
> Apple حقيقية. الواجهات هنا كاملة وجاهزة للربط، وطبقة البيانات محلية (localStorage) لأغراض العرض.

لتشغيل التوقيع الحقيقي تحتاج خادمًا (Node/PHP/Go) يوفّر:

1. **أداة توقيع** مثل [`zsign`](https://github.com/zhlynn/zsign) لإعادة توقيع `.ipa`
   باستخدام شهادة `.p12` وملف `.mobileprovision`.
2. **تخزين آمن للشهادات** — رفع `.p12` (+ كلمة المرور) و`.mobileprovision` من لوحة التحكم.
3. **استضافة `manifest.plist` و`.ipa` عبر HTTPS** (شرط إلزامي لـ `itms-services`).
4. **تسجيل الأجهزة** — إضافة `UDID` إلى ملف التعريف (لشهادات التطوير/Ad-Hoc).
5. **واجهة برمجية (API)** تستبدل استدعاءات `Saqer.api.*` في `assets/store.js`:

```
POST /api/apps            إضافة/تعديل تطبيق ورفع ملف IPA
GET  /api/apps            جلب قائمة التطبيقات
POST /api/certs           رفع شهادة (.p12 + .mobileprovision)
POST /api/sign            { appId, udid, certId }  →  { manifestUrl }
```

عند الجاهزية، بدّل جسم دوال `Saqer.api` من قراءة/كتابة `localStorage` إلى نداءات `fetch` لهذه الـ API —
دون تغيير أي شيء في الواجهات.

## التشغيل محليًا

```bash
# أي خادم ثابت، مثال:
python3 -m http.server 8080
# ثم افتح:  http://localhost:8080/index.html
```

- **لوحة التحكم:** `admin.html` — كلمة المرور التجريبية: `saqer`
- **التطبيق:** `app.html` — قابل للتثبيت على الشاشة الرئيسية (Add to Home Screen).
- البيانات تُحفظ في متصفّحك (localStorage). لإعادة الضبط: من التطبيق ← حسابي ← «إعادة تعيين البيانات».

## البنية التقنية

- **صفر تبعيات، صفر بناء** — HTML/CSS/JS فقط.
- **معزول ومتّسق** — نظام تصميم مركزي بتوكِنات CSS، وطبقة بيانات واحدة تتشاركها الواجهات الثلاث.
- **PWA** — يعمل دون اتصال عبر Service Worker، قابل للتثبيت مع أيقونات مخصّصة.
- **إمكانية الوصول** — RTL كامل، تباين مناسب، تركيز واضح، ودعم تقليل الحركة.
