# مولّد الرسوم المتحركة ثلاثية الأبعاد

الرسوم الموجودة في التطبيق الآن **ثلاثية الأبعاد (3D)**: شخصية طفل مجسّمة (رأس وجذع وأطراف عضوية ناعمة بتقنية metaballs، وجذع مخروط دوراني، ويدان بأصابع)
تتحرّك بمفاصل IK داخل مشاهد مجسّمة (حمّام بمغسلة وصنبور معدني، دُش، صحراء بصينية تراب، مسجد بسجادة)، مع إضاءة استوديو ومواد واقعية، وتُصيَّر بـ **Blender Cycles**.
فوق الإطار المصيّر تُرسم مؤثرات خفيفة ثنائية الأبعاد (عدّاد القطرات، اللمعان، موجات الصوت) من `rig.py`.

| الملف | الدور |
|---|---|
| `rig3d.py` | الشخصية ثلاثية الأبعاد (الوجه، الذراعان، اليدان، الساقان، IK)، المواد، الإضاءة، الكاميرا، المشاهد، الماء |
| `steps3d.py` | حركة كل خطوة من الخطوات الـ51 ووضعيات الصلاة (`STAND` / `RUKU` / `SUJUD` / `SIT`…)، وأغلفة الدروس `COVERS` |
| `render3d.py` | يصيّر الإطارات ويركّب المؤثرات ويصدّر MP4 (H.264) + صورة الإطار الأول |

## التشغيل

```bash
pip install bpy pycairo imageio-ffmpeg        # bpy = Blender كوحدة Python
cd ThaqafaIslamiya/Tools/Animations
python3 render3d.py out --res 540 --samples 8 --fps 15             # كل الخطوات
python3 render3d.py out wudu_06 --res 540                           # خطوة واحدة
python3 render3d.py out wudu_06 --preview 0.2,0.5,0.8               # معاينة إطارات فقط
```

ثم انسخ `out/*.mp4` إلى `ThaqafaIslamiya/Assets/Animations/`، وحوّل صورة الإطار الأول إلى `<name>_poster.jpg` بجانبه
(يعرضها التطبيق في المصغّرات والبطاقات غير النشطة بدل تشغيل الفيديو).

# المولّد ثنائي الأبعاد (الإصدار السابق)


يرسم هذا المولّد شخصية طفل بأسلوب رسومي مسطّح حديث (vector) تؤدي كل حركة في دروس الوضوء والاغتسال والتيمم والصلاة، ثم يحوّل كل خطوة إلى فيديو MP4 قصير صامت يتكرر.
الفيديوهات الناتجة موجودة في `ThaqafaIslamiya/Assets/Animations/` وتُدمج داخل التطبيق، فلا حاجة للإنترنت.

| الملف | الدور |
|---|---|
| `rig.py` | الشخصية (منظر أمامي وجانبي)، الخلفيات (الحمّام، الدُّش، الصحراء، المسجد)، الماء والتراب والمؤثرات |
| `steps.py` | حركة كل خطوة: دالة لكل معرّف مثل `wudu_05` مع مدتها بالثواني |
| `render_all.py` | يرسم الإطارات بمعدّل 24 إطارًا في الثانية ويصدّرها بـ H.264 (720×720) |
| `preview.py` / `contact_sheet.py` | صور معاينة سريعة دون تصدير فيديو |

## التشغيل

```bash
pip install pycairo imageio-ffmpeg
cd ThaqafaIslamiya/Tools/Animations
python3 render_all.py ../../ThaqafaIslamiya/Assets/Animations            # كل الخطوات
python3 render_all.py ../../ThaqafaIslamiya/Assets/Animations wudu_06     # خطوة واحدة
python3 preview.py wudu_06,salah_13 0.2,0.5,0.8 preview.png 0.4          # معاينة إطارات
```

لتعديل حركة: عدّل دالتها في `steps.py` (مواضع اليدين عبر `kf` للإطارات المفتاحية، ووضعيات الصلاة `STAND` / `RUKU` / `SUJUD` / `SIT`)، ثم أعد التصدير.
