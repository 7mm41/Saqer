# The iPhone app (technicians)

The technician app is one codebase in [`apps/tech`](../apps/tech). It runs as the PWA at
`https://<domain>/tech` and as an iPhone app built from the Xcode project
[`ios/Katf.xcodeproj`](../ios) (Capacitor 8, Swift Package Manager — no CocoaPods).

What the iPhone app adds over the PWA:

| | |
|---|---|
| Sign-in kept in the **Keychain** | Refresh token stored with `@aparajita/capacitor-secure-storage`; the API issues bearer tokens to the app |
| **Face ID** unlock | Optional, switched on in Account |
| **Camera** | Native camera for arrival, diagnosis, before/after and receipt photos |
| **GPS** | Check-in at the customer's address (geofence) |
| **New-request push with its own sound** | APNs; the sound `new_request.caf` is generated by `apps/tech/scripts/assets.mjs` and bundled |
| Arabic and English **permission texts** | `ar.lproj` / `en.lproj` `InfoPlist.strings` |
| **Privacy manifest** | `PrivacyInfo.xcprivacy`: no tracking; data collected only for app functionality |
| **Account deletion** inside the app | Account → Request account deletion |

Settings in the project: bundle ID `om.katf.pro` (placeholder), display name "Katf Pro" / "كتف للفنيين",
iPhone only, portrait, iOS 15+, push entitlement (`Katf.entitlements`).

## What is in `ios/`

| Path | What it is | Edited by |
|---|---|---|
| `Katf.xcodeproj` | The Xcode project; one target and one shared scheme, both called **Katf** | Xcode / by hand |
| `Katf/` | Swift sources, `Info.plist`, entitlements, icons, launch screen, permission texts, privacy manifest, alert sound | by hand (icons and sound: `pnpm --filter @katf/tech assets`) |
| `Katf/KatfViewController.swift` | The web view; adds the small `KatfConfig` plugin that tells the web code which server to use | by hand |
| `Katf/public/`, `Katf/capacitor.config.json`, `Katf/config.xml` | The technician app built for the iPhone, and Capacitor's settings | **generated** by `pnpm ios:sync` |
| `Plugins/` | Native sources of the Capacitor plugins (camera, GPS, push, haptics, app, Keychain, Face ID), copied from `node_modules` with their MIT licences | **generated** |
| `CapApp-SPM/` | The Swift package that links Capacitor and those plugins into the app | `Package.swift` **generated** |
| `debug.xcconfig` | Turns on Capacitor's debug logging in Debug builds | by hand |

The generated parts are committed, so the project builds on a Mac straight after cloning, without Node.
CI regenerates them on every change and fails if they differ from what is committed
([`.github/workflows/ios.yml`](../.github/workflows/ios.yml)), then builds the committed project for the
simulator on macOS **without installing Node**.

## Build and run on a Mac

Needs Xcode 16+ and internet for the first build (Xcode downloads Capacitor's Swift packages).

1. Open `ios/Katf.xcodeproj` (double-click, or `open ios/Katf.xcodeproj`).
2. Select the **Katf** scheme and an iPhone simulator → **Run** (⌘R).

### Which server the app talks to

The build setting **`KATF_API_URL`** (target **Katf** → Build Settings → User-Defined):

| Configuration | Default | Use |
|---|---|---|
| Debug | `http://localhost:4000` | The simulator on the same Mac as `pnpm dev:api` |
| Release | `https://katf.example` (placeholder) | Set your domain, for example `https://katf.om`, before archiving |

It reaches the app through `Info.plist` (key `KatfAPIURL`), so one web bundle serves every build. The API
already accepts the app's origin `capacitor://localhost`.

### After changing the technician app

```bash
pnpm install
pnpm ios:sync        # builds apps/tech for the iPhone and refreshes ios/Katf/public, ios/Plugins, CapApp-SPM
git add ios && git commit
```

Do not run `cap sync` or `cap open` directly: Capacitor's CLI only knows its own default folder layout.
`ios:sync` lets it write into a scratch folder (`apps/tech/.cap-ios`, ignored) and copies the results into
`ios/`. To add a Capacitor plugin, add it to `apps/tech/package.json` and run `pnpm ios:sync`; it is picked
up automatically.

## Before TestFlight (owner's Apple account)

1. **Apple Developer Program** membership for the company.
2. In *Certificates, Identifiers & Profiles*: create the App ID (the bundle ID you choose — update it in
   Xcode → Signing & Capabilities and in `apps/tech/capacitor.config.ts`) with **Push Notifications**.
3. Create an **APNs key** (.p8). Put its values in `deploy/.env`: `APNS_KEY_ID`, `APNS_TEAM_ID`,
   `APNS_BUNDLE_ID`, `APNS_KEY_P8_BASE64` (`base64 -i AuthKey_XXXX.p8`), and `APNS_PRODUCTION=true` for
   TestFlight/App Store builds. Restart the API.
4. In Xcode → Signing & Capabilities: choose the team; automatic signing.
5. Set `KATF_API_URL` for **Release** to your domain (see above).
6. **App Store Connect**: create the app, fill the privacy "nutrition label" to match
   `PrivacyInfo.xcprivacy` (name, phone, email, precise location, photos, financial info for payouts,
   sensitive info for identity documents, customer support, device ID — all "App Functionality", none for
   tracking).
7. Product → Archive → Distribute → TestFlight.

The App Store review needs a test account. Use a technician account on a staging server with
`DEMO_MODE=true` (clearly labelled demo data), never a real technician.
