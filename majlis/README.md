# المجلس — خدمات أصحاب الخبرة

تطبيق يسجّل فيه كل مستخدم دخوله ويعرض خدماته وخبرته: مبرمج (مع لغات البرمجة التي يتقنها)، مصمم ومونتير فيديو، ميكانيكي، كهربائي، فني تكييف، معلم تداول، مترجم… وغيرها.
العمل شخصي ومباشر بين الطرفين **بدون عقود ولا شروط سوى الخبرة**، والتطبيق يأخذ عمولة بسيطة، والدفع يتم داخل التطبيق ويُحتجز حتى اكتمال العمل.

## التشغيل

يتطلب Node.js 22.13 أو أحدث، **بدون أي مكتبات خارجية** (قاعدة البيانات SQLite مدمجة في Node).

```bash
cd majlis
npm run seed      # بيانات تجريبية (اختياري)
npm start         # http://localhost:3000
npm test          # اختبارات قواعد الدفع والإلغاء والصرف
```

حسابات البيانات التجريبية (كلمة المرور `majlis123`):

| الحساب | الجوال |
|---|---|
| المشرف | 0500000000 |
| عميلة | 0500000001 |
| مبرمج | 0500000002 |
| مونتيرة فيديو | 0500000003 |
| ميكانيكي | 0500000004 |

الواجهة تطبيق ويب قابل للتثبيت على الجوال (PWA): افتح الرابط من الجوال ثم «إضافة إلى الشاشة الرئيسية».

## المزايا

- **حساب واحد** لطلب الخدمات وتقديمها. تسجيل برقم الجوال.
- **عرض الخدمات**: التصنيف، الوصف، المهارات/لغات البرمجة، سنوات الخبرة ووصفها (إلزامي)، السعر (للزيارة/الساعة/الجلسة/المشروع)، وهل تُقدَّم **في موقع العميل** أم **عن بُعد**.
- **متصل الآن**: نقطة خضراء لحظية لكل من يفتح التطبيق، مع زر «متاح لاستقبال الطلبات».
- **البحث والتصفح**: بالتصنيف أو المهارة أو اللغة، «متصل الآن فقط»، «الأقرب لي»، الأعلى تقييماً، الأقل سعراً.
- **الذهاب لموقع العميل**: العميل يحدد موقعه، ومقدم الخدمة يحصل على الخريطة والاتجاهات، وعند ضغط «أنا في الطريق» يُشارك موقعه المباشر مع العميل.
- **محادثة** داخل كل طلب، و**إشعارات فورية** لكل تغيير.
- **تقييمات** بعد اكتمال الطلب.
- **المحفظة**: الأرباح المحتجزة، موعد الصرف القادم، سجل الصرف، ومدفوعات العميل واستردادها.
- **لوحة المشرف**: الإحصاءات، حسم النزاعات، دورات الصرف، وزر «صرف الآن».

## قواعد المال (كما طُلبت)

| الحالة | صاحب الطلب | مقدم الخدمة | رسوم التطبيق |
|---|---|---|---|
| اكتمل العمل وأكّده العميل (أو مرّت 48 ساعة دون اعتراض) | — | 100% من السعر | لا تُسترد |
| ألغى العميل **قبل** تحرّك مقدم الخدمة | يُعاد 100% من السعر | — | لا تُسترد |
| ألغى العميل **بعد** تحرّك مقدم الخدمة نحو الموقع (أو بدء العمل عن بُعد) | يُعاد 90% | **10% تعويض** | لا تُسترد |
| اعتذر مقدم الخدمة، أو تعذّر عليه الإكمال/فشل الإصلاح | يُعاد 100% | — | لا تُسترد |
| أبلغ العميل أن المشكلة لم تُحل ← نزاع: يعيد مقدم الخدمة المحاولة، أو يعيد المبلغ، أو يحسم المشرف | حسب الحسم | حسب الحسم | لا تُسترد |
| لم يقبل مقدم الخدمة الطلب خلال 24 ساعة | يُعاد 100% | — | لا تُسترد |

- يدفع العميل **سعر الخدمة + رسوم التطبيق (5%، بحد أدنى 1 ريال)**.
- المبلغ **يُحتجز في التطبيق**، وأرباح مقدم الخدمة تبقى محتجزة وتُصرف لحسابه البنكي (IBAN) **نهاية كل أسبوع** (نهاية يوم الخميس بتوقيت الرياض). يمكن جعلها كل أسبوعين بتغيير `PAYOUT_INTERVAL_DAYS=14`.
- مراحل الطلب: الدفع ← بانتظار القبول ← مقبول ← في الطريق (للخدمات في الموقع) ← جارٍ التنفيذ ← تم التسليم ← مكتمل.

كل هذه القيم في `server/config.js` ويمكن تغييرها بمتغيرات البيئة:

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `PLATFORM_FEE_RATE` | `0.05` | نسبة رسوم التطبيق |
| `PLATFORM_FEE_MIN` | `100` | الحد الأدنى للرسوم بالهللة |
| `LATE_CANCEL_RATE` | `0.1` | تعويض مقدم الخدمة عند الإلغاء بعد تحرّكه |
| `PAYOUT_INTERVAL_DAYS` | `7` | دورة الصرف بالأيام |
| `REQUEST_TIMEOUT_HOURS` | `24` | مهلة قبول الطلب |
| `AUTO_CONFIRM_HOURS` | `48` | التأكيد التلقائي بعد التسليم |
| `MIN_EXPERIENCE_YEARS` | `1` | أقل خبرة لعرض خدمة |
| `ADMIN_PHONES` | — | أرقام تُمنح صلاحية المشرف عند التسجيل |
| `PORT`, `DB_FILE`, `SECURE_COOKIES=1` | | إعدادات التشغيل |

## البنية

```
majlis/
  server/
    config.js     قواعد العمل والإعدادات
    money.js      حساب الرسوم والتسوية ودورات الصرف (دوال نقية)
    orders.js     دورة حياة الطلب، الاحتجاز، الاسترداد، المهام الدورية، الصرف
    payments.js   واجهة بوابة الدفع (بوابة تجريبية حالياً)
    events.js     تحديثات فورية (SSE) وحالة "متصل الآن" والإشعارات
    auth.js       كلمات المرور (scrypt) والجلسات
    routes/       واجهات API
    seed.js       بيانات تجريبية
  public/         الواجهة (HTML/CSS/JS بدون أدوات بناء)، قابلة للتثبيت
  test/           اختبارات node:test
```

المبالغ تُخزَّن أعداداً صحيحة بالهللة لتجنب أخطاء الكسور، وكل عملية تغيّر المال تتم داخل معاملة قاعدة بيانات واحدة.

## قبل الإطلاق الفعلي

هذه نسخة أولى كاملة الوظائف، وتحتاج قبل الإطلاق للجمهور:

1. **بوابة دفع حقيقية** (مدى/Apple Pay عبر ميسّر Moyasar أو تاب Tap): نفّذ `charge`/`refund` في `server/payments.js` واستقبل تأكيد الدفع عبر webhook. البوابة الحالية تجريبية ولا تخصم أي مبلغ.
2. **تحويل الأرباح للبنوك**: الصرف الآن يُسجَّل كـ«مدفوع»؛ اربطه بخدمة تحويلات بنكية أو صدّر قائمة الصرف للتحويل اليدوي.
3. **التحقق من رقم الجوال برسالة SMS (OTP)** عند التسجيل.
4. **الجوانب النظامية**: الاحتفاظ بأموال الغير والوساطة في الدفع قد يتطلب ترخيصاً أو العمل عبر مزوّد مرخّص (مثل حسابات الضمان لدى بوابات الدفع)، إضافة لشروط الاستخدام وسياسة الخصوصية. يُنصح باستشارة مختص.
5. إشعارات الجوال (Web Push)، رفع صور للأعمال السابقة، والتحقق من الهوية لمقدمي الخدمات في المنازل.
6. للنشر في متجر التطبيقات يمكن تغليف الواجهة الحالية بـ Capacitor بدون إعادة كتابتها.
